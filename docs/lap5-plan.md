## 5周目の方針（ユーザーと決めたこと）

- **500面では終わらない。** その先（6周目）も作る予定。ただし今は、5周目のいちばん最後の面をクリアすると「全部クリア」の画面を出してタイトルへ戻る（`stageClear` の `lap === 5` のところ）。500面を作るときに、この画面の文を新ボスに合わせて直す
- **10列。** 5周目はタイルを小さくして（幅34・高さ18）、横に10枚並べる。11行まで置ける（いちばん下の行の位置は、8列の9行とほぼ同じ）。1〜4周目は8列のまま。列の数は、面の行の字数で決まる（`GRIDS` と `setGrid`）
- **タイルが下りてくる速さ** は、401面の2.2から499面の2.4まで上げる（`DROP_V3` → `DROP_V4`）
- **新しい仕掛け**：スイッチ（`s`）、強いスイッチ（`S`）、赤い壁・青い壁（`+` `-`）、押されるタイル（`h`）、鎖のタイル（`c`）、筒（`i`）。新しいアイテム：「炎」（401面から）、「逆」（425面から）。どれもユーザーが採用と決めた
- **新しい虫は出さない**（500面の新ボスだけは出す）
- **並べ方に目新しさを出す。** ユーザーから「並べ方が同じ型ばかりで飽きる」と言われて、10列にして並べ方を見直した。さらに **425面からは、並べ方を「ひと目で何かわかる絵」にする**（星空、魚、家など）。`tint` で色をつけ、仕掛けも絵の一部にする（目をまばたきやワープの穴に、煙や星を押されるタイルに、扉を壁に、など）。ユーザーはこの方向で続けたいと言っている
- **500面のボス**：虫KING → 虫QUEEN → 2匹同時 の連戦をして、最後に新しいボスが出る

## 並べ方の決まり

`index.html` の `const STAGES5 = [` の上のコメントにも同じことを書いてある。

- 行は10字で書く。11行まで
- 割るタイルは1面40〜55枚くらい（マスが増えたぶんは、すき間にして形を作る）
- いちばん上・いちばん下の行は、横一列に埋めない
- 左右対称の面は少なくする（8面のうち1〜2面まで）。両端だけ埋めて中を空けた行（`2........2`）は作らない
- 壁で囲むところは、割れるタイルか、赤い壁と青い壁の両方でふちを作る（どちらの壁が出ていても、ボールが出入りできるように）。スイッチは、どちらのときも下から当てられるところに置く
- スイッチ・壁・鉄・錠・筒は、割るタイルのいちばん下の行より下に置かない（割れないので線に届いても止まらず、板のすぐ上まで下りてきて、はね返ったボールを受けにくくなる）
- 筒の真上のマスは空ける。すぐ上の行も、動く行や動く列の動く範囲にしない（撃ち出したボールの通り道。投げこむ虫なども、このマスにはタイルを置かない）
- ワープの穴は、組の2つとも4行目までに置く（下りてきた穴から、ボールが板の近くへ急に出てこないように）
- 動く行・動く列（の動く範囲）には、スイッチ・壁・ワープ・渦・かざぐるま・たまご・逃げる・落ちる・芽・錠・鍵・押される・鎖・筒を置かない
- かざぐるまの真上と真下のマスは空ける。落ちるタイルは、すぐ下にタイルがあるところに置く。ふたごとワープは同じ字を2つずつ
- `tint` の字：`R` 赤 `Y` 黄 `G` 緑 `A` 青緑 `B` 青 `S` 空色 `P` 桃色 `V` 紫 `K` 茶色、`.` は行ごとのふつうの色。3回のタイル（黒）と、字のある仕掛けのタイルは、それぞれの色のまま。3回のタイルは絵のふちどりに使える
- 作る8面は、それぞれ違う絵にする。これまでに使った絵（下の一覧）は使わない

### 難しさの目安

- 板を自動で動かして各面を8回以上遊ばせ（`tools/autoplay.js`）、**4周目の同じ段（面の番号から100を引いた面）** と比べる。5周目は、同じくらいか少しだけ難しくする
- 1回あたりの失ったボールは、これまでの段では多くても1.0個くらい（4周目の同じ段は0.0〜1.3個）。組み合わせ その3（457面から）では、4周目の357〜396面と比べながら、少しずつ上げてよい
- クリアまでは平均2分まで。長引くと、タイルが下りきって線に届き、そこでもボールがへる
- 長引きやすいもの：虫のいる面（ボールが遅くなる）、かためる虫、最後の1枚が押されるタイル。虫のいる面はタイルを少しやわらかくする
- 自動プレイの結果は回ごとのばらつきが大きい。迷ったら回数を12〜16回に増やす。失うボールが多い面は `--trail` をつけて、失う直前のボールの動きを見ると原因がわかる
- 4周目の面も、回数が少ないと少なめに出ることがある（379面は16回で1.3個、48回で1.6個）。比べるときは、4周目の面も同じ回数（32回くらい）で測りなおす
- 11行の面は、50秒ほどでいちばん下の行が線に届く。上に壁や大きな塊があってボールがこもりやすい面は、下の行が残ったまま線に届いてボールがへりやすい。そういう面は10行にする

## 残りの段の計画

各段は、4周目の同じ段（面の番号から100を引いた段）と同じ組み立てにする。4周目の段の中身は `index.html` の `const STAGES4 = [` のコメントを見る。

### 441〜448面：筒（4周目の341〜348面にあたる）　済

作った筒の動き（字は `i`。ユーザーには「ボールを吸いこみ、少し止めてから真上へ撃ち出す。上のほうのタイルに届きやすくなる助けのタイル」と説明して、採用になった）：

- 割れない。クリアの数に入らない（鉄と同じ `iron` で、`tube` の印をつける）。光と火は止まり、爆風でも霧でも変わらない
- ボールが当たると筒の中へ吸いこみ、`TUBE_HOLD`（0.5秒）止めてから、筒の口から上へ撃ち出す。そのあいだボールは筒の口からせり上がって見える
- 撃ち出す向きは、真上から左右どちらかへ `TUBE_TILT`〜`TUBE_TILT2`（0.1〜0.2 rad）かたむける。真上ちょうどだと、上の壁ではね返って同じ筒へまっすぐ戻り、出入りを続けてしまうため
- 撃ち出したボールは `TUBE_COOL`（1秒）のあいだ同じ筒には入らず、鉄と同じくはね返る。ほかの筒には入る
- 筒の真上のマスは、投げこむ虫・芽・たまご・押される・逃げる・落ちるタイルが使わない（`freeCell`）。面を作るときも空けておく
- 筒の中にいるときに「分」を取ると、ふえたボールは筒の口から上へ出る
- 4周目の341〜348面と比べた自動プレイ（12回以上）：1回あたりの失ったボールは0.0〜0.8個、クリアまで平均59〜108秒
