# 7周目（601〜700面）の計画

2026-11-25 にユーザーと相談して作った。「ユーザーが決めた」と書いたところは、変えるときに必ず聞く。「案」と書いたところは、Claude が出してまだ返事のないもの。作りながら直してよいが、大きく変えるときは聞く。

## 方針

- **テーマは夜。** ワシを倒したあと日が暮れて、夜になる。相手は夜の生き物で、ボスはフクロウ（ユーザーが決めた）
- **新しいタイルは4つとも入れる**：灯り・歯車・風船・ばね（ユーザーが決めた）
- **少しずつ難しくする。** 6周目の目標（失うボール1.0〜1.2個・100〜120秒）から始めて、段ごとに上げる（ユーザーの頼み。上げ幅は下の表で、2026-11-25 にユーザーが決めた）
- 作りは6周目の527面からと同じ、ふつうの面（1枚ずつ割っていく）。10列。ひと目で何かわかる絵にする。17列も使ってよい
- 8面ずつ12段（601〜696面）と、フクロウの話4面（697〜700面）。中ボスは置かない
- はじめにボーナスステージは置かない（2026-11-25。ユーザーが決めた）

## 夜の面

- 盤面が暗くなり、ボールと板のまわりしか見えない。タイルはふちだけうっすら見える
- 段ごとに2〜3面だけにする（全部の面を夜にしない）
- 夜の面には、スズメとカラスは出さない（寝ている）
- 面のキーで決める（例：`night: true`）
- **自動プレイは暗くても打てるので、夜の面の難しさは測れない。** 夜の面は目標を0.1〜0.2個低めに合わせ、遊んだときの感じはユーザーに見てもらう（案）

## 新しいタイル（4つとも採用。動きは案）

字は `TILE_HP` で使っていないものから選ぶ。足すときに直すところは now.md の「コードの場所」の最後の項目。

| タイル | 出る面 | 動き |
|---|---|---|
| 灯り | 601面から | 割ると、まわり2マスがずっと明るくなる。夜の面で「先に照らしてから割る」順番を作る |
| 歯車 | 617面から | 当てるたびに、まわり8マスのタイルが時計回りに1つずれる。回る行（loop）とちがい、絵の一部だけが回る |
| 風船 | 633面から | 上が空くと浮いていく（岩の逆）。いちばん上の行か、上のタイルにつかえると止まる |
| ばね | 649面から | 当たったボールが数秒だけ速くなる |

## 作るときにすること

- 600面のおめでとうの画面の「7周目は、これから作ります」を書きかえる。7周目の最後の面をクリアしたら、全部クリアの画面へ
- `lapOf`・`dropSpeed`・テスト（`tools/test_lap6.js` の最後の面）など、周の数で分けているところを7周目に合わせる。7周目のテストを足す
- `tools/add_stage.py` は6周目の面の最後に書き足すので、7周目の面の並び（例：`STAGES7`）へ書き足せるようにする
- 新しいタイルや生き物は、はじめて出る面の前に説明を出し（`INTROS`）、説明ページにも項目を足す
- 新しいタイルを作る段では、はじめの1面を作ったところでユーザーに見せる
