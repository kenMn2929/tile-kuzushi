### 作るときにわかったこと

- 爆弾は、まわり8マス（ななめも入る）のタイルを1回で割る。となり合った爆弾は続けて爆発する。大爆弾は2マス先まで届くので、大爆弾どうしは2マスまで離してよい。爆風は鉄も壊す（鉄はクリアの数に入らないので、残っていてもよい）
- 火は、割れた火のタイルの行だけを左右へ走り、空きを越えて端まで行く。1行に火のタイルが3枚あると、行のタイルはどれも3回ずつ火に当たる（火が火のタイルを割ると、そこからまた左右へ走るため）。だから3回のタイル（黒）も火だけで割れる
- 火で爆弾が割れると爆発する。爆風で火のタイルが割れると火が走る。爆弾から上の段へ火を渡すときは、爆弾を2つ縦に並べて、上の爆弾の爆風が上の段の火のタイルにかかるようにする
- 鎖のタイルを爆風で2枚以上割ると、つながっている鎖は全部割れる。ただし、1枚目が割れたときに鎖が切れて離れた部分は、2枚目からは伝わらない。510面のロープは、はじめ上の2枚が大爆弾の届かないところにあって、1回ぶん残った。ロープを全部、大爆弾の届くところ（4〜8行目）に置いて直した
- きっかけのタイルがいちばん下の行にむき出しだと、さいしょに打ち上げたボールが当たって1〜8秒で終わってしまう（はじめの507面は1秒）。505・507・510面は、いちばん下に鉄の机や土台を置いて、すき間の上のきっかけのタイルにしか下から当てられないようにした
- さいしょに打ち上げたボールは、まん中から左右に約0.25 rad の向きで飛ぶので、4〜6列目あたりに当たる。すき間をここに置くと、やはり1球目で当たることが多い（507面の入り口を4列目に置くと平均8秒、1秒の回も多かった）。すき間は端のほう（0・7・8列目）にした
- 504面は、はじめ通り道の右の鉄の壁を2行目から置いていて、やじるしではね返ったボールが壁の上の角に当たり、台の中へ入るのは12回のうち7回だった。壁を3行目からにして、2行目の右のタイルを外すと、24回のうち23〜24回入るようになった
- 金のタイルは、割れるたびに「福」を落とし、「きんの タイル」の知らせと音を出す。509面のように何十枚もいっしょに割れると多すぎるので、「福」は落ちてくるものがないときだけ、知らせと音は `GOLD_GAP`（0.6秒）あけて出すようにした
- 面をクリアすると、落ちてくるアイテムは消える。509面で全部いっしょに割れたときの「福」は、とる前に消える
- 508面の作りなおし：はじめの形（入り口は下の行の1マスで、入るとすぐ1行の高さの横の通り道）は、下から入ったボールが通り道の天井ではね返って、すぐ出てきてしまう。入り口を縦の通り道にすると、上りきったボールがそのまま横の通り道を跳ねながら進む
- 508面は、壁を3回のタイルにしてタイルを下ろすと、50秒ほどでうずまきの下の行が線に届き、1回あたり1.4個ボールを失った（クリアまで平均66秒）。下ろさないと0個・49秒になったので、この面だけ `still: true` でタイルを下ろさない
- 508面の3回目の作りなおし（小さいタイル）でわかったこと：
  - 横の通り道を1行の高さ（タイルの高さ12で、ボールが上下に5pxしか動けない）にすると、縦の通り道を上ってきたボールがほとんど曲がれず、60秒のあいだ一度もうずに入らない回もあった。入り口から上へ打ったボールが上の横の通り道へ曲がれる割合は、前の形で10%、横の通り道を2行にして5%、いちばん上だけ3行にして12%（`tools/` にはない、その場で作ったスクリプトで200回ずつ測った）
  - 端の列と盤面の端のすき間が12のままだと、端から3pxのところをほぼ真上へ進むボールが、盤面の壁と鉄のふちにはさまれたまま上まですべっていき、うずの上の空きで跳ね続けた。17列だけすき間を6（ボールの半径より狭い）にした（`GRIDS` の `side`）。10列の面の外のふちでも同じことが起きうるが、ほかの面は変えていない
  - 上の横の通り道の床（いちばん外の壁の上の辺）に分かれるタイルを置くと、入ってすぐ16個までふえて、うずの9割が2〜4秒で割れた。入り口と上の横の通り道に面さないところに置くと、上を少ないボールで渡ってから、右・下・左と回るあいだにふえていく
  - それでも、16個にふえると細い通り道で1秒に80〜100回ぶん当たるので、うずの9割が割れるのは、入ってから平均11秒（24回の真ん中の値は4秒。前の形は平均26秒で、1秒に20回ぶんほど）。ボールの上限を12個にしても変わらず、分かれるタイルを4枚にへらすと、ふえきらない回が長引いて平均94秒になった
  - ボールが同じ向きに回り続けるかを、うずの中心のまわりを回った角度で測ると、前の形も今の形も、1回の面で合わせて1周ほどしかなかった（曲がり角で半分ほどはね返り、行ったり来たりする）。この面だけ、うずの中のボールを時計回りの向きへ押す流れも試したが、細い通り道では向きを逆にできず、かえって真ん中に着きにくくなったので入れなかった
  - 壁を全部鉄にして、通り道の内がわに3回のタイルをはりつける形も考えた。うずの形は最後まで残るが、同じ広さで2周しか巻けないのでやめた

## 511〜600面の計画（2026-11-15 にユーザーと話して決めた）

「ユーザーが決めた」と書いたところは、ユーザーが自分の言葉で決めたこと。変えるときは必ず聞く。
「案」と書いたところは、Claude が出してユーザーに見せ、反対がなかったもの。細かい数字や動きは、作って遊んでもらいながら直してよい。大きく変えるときは聞く。

### 方針（ユーザーが決めた）

- **511〜600面は、「道を開いて、きっかけに当てると、一気に割れる」面にする。** ボーナスステージ（501〜510面）の気持ちよさを、ふつうの難しさの面に組みこむ。5周目のような「新しい仕掛けを重ねていくだけの周」にはしない（5周目の組み合わせ その3を40面作って、重ね方は出しきった。「同じ型ばかりで飽きる」と前に言われている）
- 600面まで作る（残り90面）
- **きっかけに当てなくても、ふつうに割っていけばクリアできるようにする。** 連鎖は近道で、ただ一つの道にはしない。鉄だけで囲んだ面は作らない（ただ一つの道になっているのは501〜510面だけ）
- 小さいタイル（17列）は、508面のあとも使う
- 新しいタイルは4つ：導火線・水・時限爆弾・岩（導火線・水・時限爆弾は「即採用」、岩は「面白いかも」で入れた）
- **虫は卒業する。新しい相手は鳥。** ふつうの面はスズメのような小さい鳥、ボスだけワシなどの猛禽類の、少しこわい鳥にする
- 虫は6周目にも出してよい。スズメが虫をくわえて飛んでいく演出を入れる
- **中ボスは置かない**（これまでの周と同じ）。ボスは600面だけ。**597・598・599・600面の4面で、ボスへの話を作る**
- ボスは、ボールを何度も当ててやっつけるのではなく、**盤面のからくりを動かしてやっつける**（ユーザーが「とても面白い」と言った）
- 508面を3回作りなおしたときのユーザーの声は、いつも「ダダダダっと進む」「ガガガガっとぐるぐる回る」「爽快感」だった。面を作るときは、これを物差しにする

### 二段の作り（案）

- 1面を、前半と後半に分けて考える。**前半**は、きっかけ（導火線の端、時限爆弾、水のタイルなど）へ行く道を開くところで、ふつうの面と同じ手ごたえにする。きっかけは、鉄・錠・壁・3回のタイル・虫や鳥の奥に置く。**後半**は、きっかけに当たってから連鎖で一気に割れるところ
- 目安：きっかけに当たるまで60〜90秒、当たってから割りきるまで5〜15秒。クリアまで平均2分まで、1回あたりの失ったボールは0.5〜1.0個くらい（5周目と同じ物差し。`docs/lap5-plan.md` の「難しさの目安」）
- 自動プレイで「きっかけに当たるまで」と「きっかけからクリアまで」を分けて測る（`tools/autoplay.js` を直す）。連鎖で割れたタイルが全体のどれくらいかも出せるとよい
- 501〜510面でわかったことは、そのまま使う（上の「作るときにわかったこと」）。とくに、きっかけがいちばん下の行にむき出しだと1球目で終わる、4〜6列目のすき間は1球目で当たりやすい、の2つ
- ボールは、511面からもほかの面と同じくへる。501〜510面もいまのまま（前から残っていた宿題。案として見せて、反対はなかった）
- 5周目の425面から続けた「ひと目で何かわかる絵」は続ける。`docs/lap5-plan.md` の「これまでに作った面」の一覧とかぶらない絵にして、新しいタイルも絵の一部にする（導火線は花火やろうそくの芯、水は滝や雨どい、岩は落石、など）。並べ方の決まりも、5周目のものを守る。ただし、連鎖をつなげるために要るところは、ボーナスステージと同じく外してよい

### 新しいタイル（4つとも採用。動きは案）

字は、`TILE_HP` で使っていないものから選ぶ。足すときに直すところは、`docs/lap5-plan.md` のいちばん下に並べてある。

| タイル | 動き | ほかとの関わり |
|---|---|---|
| 導火線 | 割れると、上下左右のとなりの導火線へ、0.1秒ずつ順に火が移っていく。曲がり角も進み、分かれ道では両方へ進む。火が通ったところは割れる | 火のタイルの火や爆風でも火がつく。端のとなりに爆弾や大爆弾を置けば爆発する。スズメがとまっているところは火が通らない |
| 水 | 割れると水が真下へ流れ、その列のタイルを底まで1回ずつたたく。鉄で止まる | 火のついた導火線と、火のタイルの火を消す（先に水を流すと、そこから先へ火が進まない）。助けにも、じゃまにもなる |
| 時限爆弾 | 当てると3秒数えて爆発する。数えているあいだは数字が見える | 導火線の火が届くと、数えずにすぐ爆発する。数えているあいだにほかのきっかけも動かして、同時に爆発させる面が作れる |
| 岩 | 割れない。クリアの数に入らない。下の支えがなくなると落ち、下のタイルをつぶしながら、鉄か底まで行く | 爆風では壊れない。水では動かない |

- いまある連鎖は、爆弾（まわり8マスへ）、火（行を左右へ）、鎖（つながり全部を一度に）の3つ。新しい4つは、足りなかった「順番に走る」「曲がる」「縦に伝わる」「間をおく」を足すためのもの
- 導火線は、508面でほしかった「ガガガガっとぐるぐる回る」を、ボールの動きにたよらずに出すためのもの。17列の面でうずまきや長い道にすると、いちばん生きる
- 水が火を消すので、「割る順番を考える」面が作れる
- 505・510面は、導火線を爆弾の並びで作っている。この2面は変えない
- 新しいタイルごとに、はじめて出る面の前に説明を出す（`INTROS`）。説明ページにも項目を足す

### 小さいタイル（17列）の使い方（案）

- 全部の面を17列にはしない。うずまきや長い導火線のように、連鎖の長さを見せたい面は17列、絵と仕掛けを見せたい面は10列にする
- 17列の面は、ボールの通り道を2行（2列）より細くしない。508面で、1行の通り道では曲がれなかった
- 17列の面の端のすき間（`GRIDS` の `side`）と字の大きさ（`tileFont`）は、508面で作ったものを使う。新しいタイルの絵は、小さいタイルでも見分けられるようにする

### 鳥（スズメとボスの猛禽類はユーザーが決めた。カラスと動きは案）

| 鳥 | 出る面 | すること |
|---|---|---|
| スズメ | 511面で絵だけ。527面から動く | 飛んできてタイルにとまる。とまっているタイルは割れず、導火線の火も通らない。ボールが近くに当たると飛び立つ。虫がいると、先にそちらを食べに行く（虫をへらしてくれる）。食べ終わると、とまりに来る |
| カラス | 559面から | 光るものを持っていく。落ちてくるアイテムを横取りする。導火線を1枚くわえて、別のところへ置く（道が切れる。置いた先でつながることもある） |
| ワシ | 597〜600面 | ボス。下に書く |

- スズメは、ボールをはじくだけのじゃまにはしない。「追いはらってから火をつける」というひと手間を作るもの
- 511面のはじめに、歩いている虫をスズメがくわえて飛んでいく場面を入れて、相手が代わったことを見せる（ユーザーが「オッケー」と言った）
- 虫取り網を持った子どもを最後の相手にする案も出したが、ユーザーは鳥を選んだ。使わない

### 597〜600面とボス（4面で話を作るのはユーザーが決めた。中身は案）

5周目の497〜500面と同じ運びにする（`docs/lap5-plan.md` の「497〜500面」）。

| 面 | 中身 |
|---|---|
| 597 | スズメしかいない面。面の途中で、大きな影が一度だけ盤面を横切る。クリアすると「スズメたちが、空を見上げておびえている。何がいるのだろう」のような一言を出す（`STORY`） |
| 598 | ワシが上を通りかかる。来ると、スズメがいっせいに飛び立つ。まだ何もしてこない |
| 599 | ワシが回って飛び、導火線を切りに下りてくる。盤面に大砲があるが、撃ってもよけられて、まだやっつけられない。面の前の説明でワシを知らせる（`INTROS`） |
| 600 | たたかう |

600面のたたかい：

- 盤面に大きなからくりがあり、導火線の先の大砲（筒の強い版）がワシへ撃つ。3回当てるとやっつける
- 1回当てるたびに、からくりが組み変わる（1回目は導火線だけ、2回目は水と時限爆弾も、3回目は岩も入る）
- ワシは上を回って飛び、ときどき急に下りて、導火線を1枚つかんで切る。切れたところは、つなぎなおせるようにする（アイテムか、となりのタイルを割ると出てくる替えの導火線）
- ボールをワシに当てても体力はへらない。ひるんで、少しのあいだ下りてこなくなるだけ
- おこると、羽ばたきの風でボールを横へ流す
- 599面で大砲をよけられるようにしておき、600面では、おこって下りてきたところを撃つ形にして、当たったときの手ごたえを出す
- 600面をクリアしたときの画面と、そのあと（7周目を作るか）は、まだ話していない
