## 並べ方の決まり

- 行は10字、11行まで。割るタイルは1面40〜55枚くらい、硬さの合計は90〜110回ぶんくらい（7周目は難しさを上げるので、60枚・硬さ130くらいまで出ている）
- いちばん上・いちばん下の行は、横一列に埋めない。両端だけ埋めて中を空けた行（`2........2`）は作らない
- 左右対称の面は、8面のうち1〜2面まで（601〜608面では602・604面）
- スイッチ・壁・鉄・錠・筒は、割るタイルのいちばん下の行より下に置かない
- 岩（`@`）のすぐ下には、動かないタイルを置く（いちばん下の行の岩はよい）
- 動く行・回る行・縦に動く列には、スイッチ・壁・ワープ・渦・かざぐるま・たまご・逃げる・落ちる・芽・錠・鍵・押される・鎖・筒・導火線・水・灯りを置かない（盾ややじるしは置いてよい）
- 筒の真上は空ける。かざぐるまの真上と真下は空ける。ワープは4行目までに置き、組の2つとも置く。落ちるタイルは、すぐ下にタイルがあるところに置く
- 壁で囲むところは、割れるタイルか、赤い壁と青い壁の両方でふちを作る。スイッチは、どちらのときも下から当てられるところに置く
- 上が割れない鉄でふさがった面は、`without: ['up']` を書く（`tools/check_up.js` で調べる）
- 夜の面（`night: true`）には、スズメとカラスを書かない。ホタル（`firefly`）は夜の面にだけ書く（どちらも `check_stages.py` で調べる）。灯り（`l`）は夜の面の絵の明かり（窓・火など）に使う（動きはふつうの1回のタイルと同じ）
- `tint` の字：`R` 赤 `Y` 黄 `G` 緑 `A` 青緑 `B` 青 `S` 空色 `P` 桃色 `V` 紫 `K` 茶色、`.` は行ごとの色。3回のタイルは黒、字のある仕掛けのタイルは、それぞれの色のまま
- 絵は、下の「使った絵」とかぶらないものにする。絵の中のものと仕掛けの組み合わせも、前と同じにしない（荷物を落ちるタイル、鳥を押される、つるすひもやつなを鎖、ひさしや屋根を盾、明かりやランプ・窓・きらめきを強いまばたき、走って逃げる人を強い逃げる、窓やろうそくの火や提灯を灯り、串を鎖、枕をふたご、歯を盾、かごの中の虫や街灯を灯り、カブトムシのはねをふたご、ビー玉を落ちる、とうもろこしの皮を鎖、セミのはねを逃げる、うちわの風をやじるし、などはもう使った）

## 難しさを合わせるときにわかっていること

- 物差しは527〜534面（128回ずつで平均1.04個・117秒）と、601〜608面（128回ずつで1.0〜1.3個・90〜120秒、平均1.14個・101秒）
- 自動プレイは回ごとのばらつきが大きい。形をしぼるあいだは64回、決めるときは128回で測る（128回でも0.1〜0.2個、5秒ほど上下する）
- 失うボールをふやすのによく効くのは、いちばん下の行（10〜11行目）に盾を1〜2枚置くこと。盾2枚で0.3〜0.5個ふえる。低いところの3回のタイルや鉄も、失うボールをふやす
- タイルを固くしても、のびるのは時間で、失うボールはあまりふえない。やわらかくすると時間も失うボールもへる
- 大きな塊を上のほうに置く面は、やさしい。行の数が少ない面もやさしい
- 漂う虫の面は、ボールが遅くなるので長引く。虫のいる面はタイルをやわらかくする
- スズメは、失うボールより時間を長くする（2羽で30〜35秒）。ただし603面のように鎖でまとめて割れる面では、スズメを3羽から4羽にしても時間がのびなかった
- 分かれるタイルを、いちばん下の行や囲いの中、上の端に置くと、ボールがすぐ8つにふえて、すぐ終わる
- 601〜608面のはじめの下書き（45〜55枚・硬さ60〜105）は、0.1〜0.7個・60〜85秒とやさしく出た。7周目の目標に入れるには、盾を2〜4枚と、低い行の3回のタイルが要った
- 鎖（603面の串）は3回当てると串がまるごと割れるので、短く出やすい。下に鍋のふち（2回のタイル1行）と盾5枚を足して、1.2〜1.3個・96〜98秒（目標より少し短い）。鍋のふちを3にすると、盾が鍋に隠れて2.2〜2.6個にはね上がった
- 609〜616面は128回で1.0〜1.3個・94〜112秒（夜の面は1.0〜1.2個）。ホタルは自動プレイの数字に関わらない。613・616面は測るたびに1.1〜1.5個とゆれた。616面は盾を1枚はずして1.1個・100秒
- 夜の面は、自動プレイでは夜風がほとんど数字に出ない（板が毎秒560pxで、曲がったボールに追いつく。`WIND_K` を2.4まで上げても、自動プレイに0.3秒の遅れをつけても変わらなかった）。暗かったころと同じく、目標を0.95〜1.15個にしておく。夜風にしたあとの128回：601 1.0個・98秒、604 1.0個・85秒、607 0.9個・95秒、609 0.9個・92秒、612 1.1個・95秒、615 1.0個・93秒
- 618〜624面は128回で1.0〜1.3個・98〜115秒（夜の619は1.0個・114秒、623は1.1個・98秒）。映写機（619）は低い盾を8枚置いても0.8〜0.9個どまりで、いちばん下の行に床のタイルを足して1.0個になった。タイルが上の塊だけの面は、下の行を埋めるほうが盾より効く
